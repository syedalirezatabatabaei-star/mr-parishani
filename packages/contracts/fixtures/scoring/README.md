# آزمون‌های طلایی امتیازدهی (تسک ۳-۱)

`golden-v1.json` ترکیب‌های ورودی و خروجی موتور امتیاز است (سند ۰۳ §۹). **هر خروجی مورد انتظار را خود Microsoft Excel از فایل کارفرما محاسبه کرده است.**

- فایل کارفرما: `docs/source/فرم_امتیازدهی_وام_و_ضامن_سپهر.xlsx`
- ورودی‌ها در برگه «فرم ارزیابی» وارد شده‌اند، همان‌طور که فهرست کشویی آن وارد می‌کند.
- هیچ عددی دستی نوشته نشده است.

## محتوا

| کلید          | معنا                                                                                   |
| ------------- | -------------------------------------------------------------------------------------- |
| `source`      | نام فایل، SHA-256 آن، نسخه Excel. آزمون پوشش بررسی می‌کند فایل `docs/source` همان است. |
| `outputs`     | هر خروجی نام‌دار و خانه برگه «فرم ارزیابی» که از آن خوانده شده است.                    |
| `formulas`    | فرمول هر خانه خروجی، عین فایل (منبع هر عدد مورد انتظار).                               |
| `validations` | منبع فهرست کشویی هر خانه ورودی (برای EXCEL-BUG-7).                                     |
| `options`     | گزینه‌های هر معیار: کد پایدار انگلیسی، خانه «جداول پایه»، برچسب فارسی و امتیاز.        |
| `cases`       | ترکیب‌ها: `inputs`، `expected`، `covers` (مورد اجباری پوشش‌داده‌شده) و `excelBug`.     |

**قراردادها:**

- `null` یعنی خانه در اکسل خالی است (`""`).
- مبلغ را اکسل به **تومان** می‌گیرد؛ `amountRial = amountToman × 10` (قاعده ۱ CLAUDE.md).

## ساخت دوباره (فقط ویندوز با Excel)

```
cd packages/contracts/fixtures/scoring
node tools/cases.mjs > tools/cases.json
powershell -NoProfile -ExecutionPolicy Bypass -File tools/evaluate-in-excel.ps1
node tools/assemble.mjs
```

- **`cases.mjs`** فقط می‌گوید **کدام ورودی‌ها** آزموده شوند. ترکیب‌های مرزی را با جست‌وجو پیدا می‌کند: عددی که با گزینه‌ها به دست نمی‌آید (جمع ۷۹ برای وام‌گیرنده) با نزدیک‌ترین عدد هم‌طرف جایگزین می‌شود.
- **`evaluate-in-excel.ps1`** یک رونوشت موقت از فایل را فقط‌خواندنی باز می‌کند، هر ترکیب را وارد می‌کند، دوباره محاسبه می‌کند و خانه‌های خروجی را می‌خواند. فایل اصلی دست نمی‌خورد.
- **`assemble.mjs`** خروجی Excel را به همین فایل تبدیل می‌کند.

آزمون پوشش (`src/scoring/golden-coverage.test.ts`) بدون Excel اجرا می‌شود. اگر یکی از موارد اجباری سند ۰۳ §۹ جا بیفتد، فایل با خودش ناسازگار باشد، یا فایل اکسل عوض شده باشد، شکست می‌خورد.

ترکیب‌های مربوط برچسب `EXCEL-BUG-n` دارند. رفتار اکسل همان‌طور که هست ثبت شده و **هیچ‌کدام بی‌صدا اصلاح نمی‌شود** (سند ۱۰ §۵):

- ۱ تا ۶: سند ۰۳ §۷.
- ۷ و ۸: یافته‌های تسک ۳-۱ (`docs/decisions/task-3-1-decisions.md`).
