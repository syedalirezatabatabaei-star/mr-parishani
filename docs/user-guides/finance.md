# حسابداری و تسویه (مالی)

**بخش‌های منو:**
- «تأیید فیش‌ها»، «فیش اقساط»، «چک‌ها: اجرا و استرداد»؛
- «تأیید شارژ»، «عملیات ویژه»؛
- «تسویه پزشکان»، «نرخ‌های تسویه پزشک»، «مجوزهای خدمت».

1. **«تأیید فیش‌ها»:** فیش هزینه تشکیل پرونده، کارمزد و پیش‌پرداخت. مبلغ را با فیش بانکی، **به ریال و دقیق**، تطبیق دهید.
2. **«فیش اقساط»:** تأیید یا رد، صورت‌حساب بانک، و مانده حساب معلق (تعیین تکلیف دستی، پاسخ ۶.۷).
3. **«تأیید شارژ»:** شارژ کیف اعتبار پرونده تکمیل‌شده، فقط برای درخواست دیگران.
4. **«تسویه پزشکان»:** صورت‌وضعیت‌ها، پرداخت با تأیید دوم، گزارش‌ها و خروجی Odoo. روز هدف پرداخت ۱۰ هر ماه (پاسخ ۵.۲).
5. **«نرخ‌های تسویه پزشک»:** کارمزد خدمت اعتباری و نقدی و دوره تسویه. پیشنهاد و تأیید دونفره؛ هر خدمت نرخ زمان خودش را دارد.

**هرگز:** اصلاح ثبت مالی بی سند معکوس (قاعده ۳). اگر عددی با دفتر کل نمی‌خواند، دستورالعمل `docs/runbooks/ledger-mismatch.md`.
