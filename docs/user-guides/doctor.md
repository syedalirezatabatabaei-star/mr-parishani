# پزشک

**پنل مراکز.** همان بخش‌های [مدیر مرکز](center.md)، به اندازه مجوز پزشک.

1. **«نوبت‌ها»:**
   - تأیید یا رد درخواست نوبت (اگر حالت تأیید دستی است)؛
   - پذیرش بیمار با کد حضور؛
   - ثبت «معاینه شد».

   **ثبت معاینه پیش از صدور پیش‌فاکتور لازم است.**
2. **«بیماران اعتباری»:** بیمار دارای کیف اعتبار نزد شما.
   - ثبت خدمت: مجوز خدمت با کد بیمار، که ۱۰ دقیقه اعتبار دارد (پاسخ ۴.۶).
   - خدمت تا قطعی شدن قابل لغو با دلیل است.
3. **«تسویه»:** صورت‌وضعیت خودتان.
4. **منشی‌ها:** در «پزشکان و منشی‌ها» نقش منشی را به حساب منشی خودتان می‌دهید یا پس می‌گیرید (`access.manage_secretaries`).
5. **«حساب من»:** موبایل حساب لازم است تا پیامک «بیمار آماده است» به شما برسد (ف۴).
