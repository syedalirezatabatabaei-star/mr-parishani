# کارشناس و مدیر شبکه درمان

**بخش‌های منو:** «بررسی مراکز»، «بررسی پروفایل‌ها»، «ورود از اکسل»، «تعطیلات».

## کارشناس شبکه

1. **«بررسی مراکز»:** مرکز تازه یا در انتظار بررسی.
   - هر مدرک را «دریافت‌شده» و سپس «تأییدشده» کنید.
   - سپس «پیشنهاد فعال‌سازی» با دلیل. فعال‌سازی را نفر دوم تأیید می‌کند.
2. **«بررسی پروفایل‌ها»:** نسخه تازه پروفایل پزشک پیش از انتشار عمومی.
3. **«ورود از اکسل»:** دسته مراکز و پزشکان. الگو، بارگذاری، پیش‌نمایش ردیف‌های ردشده با دلیل، و سپس ثبت. الگوها در `docs/import-templates`.
4. **تعلیق مرکز:** با دلیل. نوبت تازه بسته می‌شود؛ آنچه پیش‌تر ثبت شده ادامه دارد.

## مدیر شبکه

- **«تأیید درخواست»** فعال‌سازی و بازفعال‌سازی مرکز، فقط برای پیشنهاد دیگران (سند ۰۴ §۵).

**نمی‌بینید:** هیچ داده مالی بیمار یا پرونده اعتباری.
