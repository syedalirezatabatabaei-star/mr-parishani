# منشی

**پنل مراکز.** فقط بخش‌هایی که پزشک به شما داده است، معمولاً «نوبت‌ها» و «تقویم کاری».

1. **«نوبت‌ها»:** تأیید درخواست‌ها، تغییر زمان و پذیرش بیمار با کد حضور.
2. **«تقویم کاری»:** ساعت‌ها و استثناهای همان پزشک.
3. **پیش‌فاکتور، خدمت اعتباری و تسویه** مگر پزشک صریحاً داده باشد، در منوی شما نیست.

اگر پزشک نقش را پس بگیرد، از همان لحظه آن بخش‌ها ۴۰۳ می‌دهند.
