# پشتیبانی

**بخش‌های منو:** «تیکت‌ها»، «داشبورد واحدها»، «پیامک» (اگر نقش شما مجوزهای پیامک را دارد).

1. **«تیکت‌ها»:** صف هر واحد با مهلت پاسخ (پیش‌فرض ۲۴ ساعت کاری؛ پاسخ ۷.۵).
   - پاسخ به بیمار؛
   - یادداشت داخلی، که بیمار نمی‌بیند؛
   - ارجاع به واحد دیگر؛
   - بستن.

   بیمار تا ۷ روز می‌تواند بازش کند.
2. **«داشبورد واحدها»:** مهلت‌های در خطر و بار کارشناسان.
3. **«پیامک»:** قالب‌ها، زمان‌بندی و گزارش. ارسال گروهی بالای ۲۰۰ گیرنده تأیید نفر دوم می‌خواهد (پاسخ ۶.۶).

**نمی‌توانید:** تراکنش مالی را تغییر دهید. درخواست مالی را به واحد مالی ارجاع دهید.
