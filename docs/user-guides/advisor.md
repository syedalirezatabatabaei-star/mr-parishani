# مشاور (حامی)

پنل داخلی، صفحه **«سرنخ‌ها و پرونده‌ها»** (`/leads`؛ ساخته ۱۴۰۵/۰۷/۲۴، `bca8a61`). کار مشاور در سند ۰۵ و ۰۸:
- سرنخ‌های واگذارشده به خود را پیگیری می‌کند؛
- سرنخ تازه را دستی ثبت می‌کند («ثبت سرنخ»)؛
- وضعیت پرونده (Case) را جلو می‌برد («شروع مشاوره»، بستن با علت فهرست‌شده)؛
- برای بیمار نوبت می‌گیرد («نوبت برای بیمار»، `booking.book_for_patient`).

**قاعده‌های نقش:**
- فقط پرونده‌های واگذارشده به خودش (R18: دامنه `own`، در فرم «فقط رکوردهای خودش»). اگر مدیر استراتژی پرونده را به مشاور دیگری منتقل کند، پرونده از فهرست شما می‌رود.
- خود مشاور پرونده را منتقل نمی‌کند؛ برای تحویل به همکار به مدیر استراتژی بگویید.
- تصمیم اعتباری را نمی‌بیند (سند ۰۴ §۳)؛ فقط «در بررسی، تأیید، رد» پرونده خودش.
- افزودن موبایل به شخص موجود با کد ملی، تا تأیید صاحب شماره یا تأیید دونفره کارکنان، به حساب دسترسی نمی‌دهد (م۵ و م۷).
