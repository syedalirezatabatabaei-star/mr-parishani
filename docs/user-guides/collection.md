# واحد معوقات

**بخش منو:** «معوقات و وصول»: صف معوقات، اقدام و وعده، پیشنهادهای تشدید.

1. **صف:** اقساط سررسیدگذشته، با روزهای تأخیر.
2. **اقدام:** ثبت تماس، نتیجه و وعده پرداخت با تاریخ. یادآوری پیامکی خودکار است (۱، ۷ و ۱۵ روز پس از سررسید؛ پاسخ ۶.۳).
3. **تشدید:** پیشنهاد مرحله بعد طبق جدول سند ۱۵ §۵. تصمیم با `collection.decide_escalation`.
4. **چک:** اجرای چک دو تأیید دارد، مدیر وصول و مالی («چک‌ها: اجرا و استرداد»).

**نمی‌بینید:** شرح درمان بیمار (سند ۰۴ §۳). صفحه پرونده «بی اطلاعات درمان» است.
