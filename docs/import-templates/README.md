# الگوهای ورود گروهی

الگوی برگه‌هایی که ورود گروهی تسک ۲-۹ (سند ۰۸ بخش ۱۲، سند ۰۵ بخش ۸) می‌پذیرد. هر فایل فقط سطر عنوان دارد و ستون‌ها دقیقاً همین نام‌ها هستند.

## `treatment-fields.csv` — فیلدهای درمان (تسک ۲-۴، ADR-024)

فیلدهای پایلوت با این برگه وارد می‌شوند (`TODO(decision)`: فهرست خود فیلدها با مالک است). مجوز لازم: `catalog.manage_catalog` (مدیر شبکه درمان یا مدیر سیستم). این برگه پیش از برگه خدمات و تعرفه‌ها پردازش می‌شود، چون هر خدمت به کد فیلد ارجاع می‌دهد.

| ستون | اجباری | قاعده |
|---|---|---|
| `code` | بله | لاتین کوچک، رقم و `_`؛ با حرف شروع شود؛ ۲ تا ۶۳ نویسه (مثل `dental`). **برای همیشه یکتا**؛ کد کنارگذاشته‌شده دوباره پذیرفته نمی‌شود. |
| `name` | بله | نام فارسی، ۲ تا ۱۰۰ نویسه؛ پیش از ذخیره یکسان‌سازی می‌شود («ي/ك» و ارقام). بین فیلدهای فعال یکتا. |
| `sort_order` | خیر | عدد صحیح ۰ تا ۱۰۰۰۰ برای ترتیب نمایش؛ خالی = ۰. |

خدمت ویژه «ویزیت» در هیچ فیلدی نیست و در این برگه نمی‌آید؛ مهاجرت `0012` آن را ساخته است.
