# ۰۳ — موتور امتیازدهی و تصمیم اعتباری

منبع: فایل «فرم امتیازدهی وام و ضامن سپهر». همه جدول‌ها **داده نسخه‌دار** هستند، نه کد.

## ۱. جریان پلکانی

```
۱) ثبت داده خام وام‌گیرنده → محاسبه امتیاز → رتبه (الف/ب/ج/د)
۲) سطح مبلغ از مبلغ درخواستی → کم / متوسط / زیاد / خارج از سقف
۳) ماتریس (رتبه × سطح مبلغ) → ضمانت لازم
۴) معرفی و اعتبارسنجی ضامن‌ها → رتبه هر ضامن
۵) کنترل کفایت ضامنین → کافی / ناکافی
۶) تعیین مرجع تصمیم → ثبت تصمیم کارشناسی
```

ضامن پیش از تعیین رتبه وام‌گیرنده درخواست نمی‌شود.

| سطح | دامنه (پیکربندی) |
|---|---|
| کم | تا ۴ میلیون تومان |
| متوسط | بیش از ۴ تا ۱۲ میلیون تومان |

## ۵. ماتریس ضمانت لازم

| رتبه × سطح | ضمانت لازم | کفایت |
|---|---|---|
| الف · کم | بدون ضامن شخص ثالث | همیشه کافی |
| الف · متوسط | یک ضامن حداقل قابل قبول | `max(w) ≥ 2` |
| الف · زیاد | یک ضامن ممتاز + تصویب مسئول اعتبار | `max(w) = 3` |
| ب · کم | یک ضامن قابل قبول | `max(w) ≥ 2` |
| ب · متوسط | یک ممتاز یا دو قابل قبول | `max(w)=3` یا هر دو `≥2` |
| ب · زیاد | دو ضامن، حداقل یکی ممتاز + ارجاع | `w1+w2 ≥ 5` و `min(w) ≥ 2` |
| ج · کم | یک ضامن ممتاز | `max(w) = 3` |
| ج · متوسط | دو ضامن: یک ممتاز و یک قابل قبول | `max(w)=3` و `min(w) ≥ 2` |
| ج · زیاد | رد استاندارد؛ فقط با وثیقه و تصویب کمیته | — |
| د · هر سطح | رد | — |

`w` = وزن رتبه ضامن (۳ ممتاز، ۲ قابل قبول، ۱ تکمیلی، ۰ غیرقابل قبول)

## ۶. مرجع تصمیم

| شرط | مرجع |
|---|---|
| رتبه د یا شرط توقف | رد؛ بدون اختیار عبور فردی |
| سطح زیاد یا رتبه ج | کمیته ریسک و اعتبار |
| سطح متوسط یا ضمانت دوضامنه | مسئول یا مدیر اعتبار |
| سایر | کارشناس اعتبار + کنترل دوم |

کمیته شامل واحد استراتژی، واحد وصول و واحد مالی است. تصمیم خارج از جدول نیازمند دلیل مکتوب، نام تصویب‌کننده و مصوبه کمیته است و در سابقه ثبت می‌شود.

## ۸. الزامات پیاده‌سازی

1. **داده خام ثبت شود، نه دسته انتخابی.** کارشناس سال‌های اشتغال، مبلغ تعهدات، میانگین مانده و مبلغ قسط را وارد می‌کند و سامانه دسته را تعیین می‌کند. هر عدد مدرک پشتیبان دارد.
2. **هیچ داده پزشکی وارد امتیاز نمی‌شود** (قاعده صریح فایل کارفرما).
3. **نسخه‌بندی:** هر پرونده به `ruleset_version` زمان بررسی قفل می‌شود. فعال‌سازی نسخه جدید نیازمند گذر از آزمون‌های طلایی و تأیید دونفره است.
4. **شفافیت:** خروجی موتور شامل امتیاز هر معیار، رتبه، سطح مبلغ، ضمانت لازم، کفایت و مرجع تصمیم است و همه در پرونده ذخیره می‌شود.
5. **تصمیم نهایی انسانی است.** موتور پیشنهاد می‌دهد؛ ثبت تصمیم بدون دلیل ممکن نیست.
6. **رضایت بررسی اطلاعات** برای وام‌گیرنده و هر ضامن جداگانه گرفته و ثبت می‌شود.
7. ضامن نباید امتیاز و دلایل رد وام‌گیرنده را ببیند؛ فقط حدود تعهد خودش را.

## ۹. آزمون‌های طلایی

از فایل اکسل حداقل ۴۰ ترکیب استخراج و به‌صورت جدول ورودی/خروجی در `packages/contracts/fixtures/scoring/` ذخیره می‌شود. هر تغییر در موتور یا نسخه قواعد باید این آزمون‌ها را بگذراند. موارد اجباری:

- هر شرط توقف، هر دو طرف مرز امتیاز (۴۴/۴۵، ۵۹/۶۰، ۷۹/۸۰)
- هر ۱۲ سلول ماتریس، هر سه ترکیب وزنی ضامن‌ها
- مبلغ دقیقاً روی مرز سطح (۴ و ۱۲ و ۲۰ میلیون)، و خارج از سقف
- پرونده با داده ناقص (نباید امتیاز تولید کند)
