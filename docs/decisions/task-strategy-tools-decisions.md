# ابزارهای مدیر استراتژی در پنل (۱۴۰۵/۰۷/۲۴، دور بیستم)

تصمیم مالک: ش۴ (انتقال صف را عوض نمی‌کند) فعلاً می‌ماند و فقط در راهنمای مدیر استراتژی ذکر می‌شود؛ انتقال پرونده سرنخ فقط با مدیر استراتژی می‌ماند.
غیرمالی، بی مهاجرت، بی endpoint و بی مجوز تازه: هر سه API از پیش بود و صفحه نداشت.

## یافته

- **انتقال دستی پرونده** (`POST /lead/cases/:id/assignments`، `lead.assign_manually`) در هیچ صفحه‌ای نبود؛ راهنمای مشاور و مدیر سیستم می‌گفتند «از مدیر استراتژی بخواهید»، ولی او فقط با API می‌توانست.
- **علت‌های بستن** (`lead.manage_reasons`) و **مسدودی شخص** (`lead.block_person`) هم صفحه نداشتند.

## تصمیم‌ها

1. **انتقال:** فرم «انتقال به کارشناس دیگر» در صفحه پرونده (`/leads/:id`)، فقط برای پرونده باز. کارشناس با نام کاربری یافته می‌شود (همان `GET /lead/agents/by-username/:username` صفحه تخصیص، `lead.manage_assignment`)؛ پس فرم برای کسی است که هر دو مجوز را دارد (امروز فقط مدیر استراتژی). متن فرم ش۴ را می‌گوید.
2. **علت‌ها:** صفحه `/leads/reasons` (فهرست، علت تازه، ویرایش عنوان و ترتیب، کنار گذاشتن)، با پیوند در بالای `/leads` فقط برای `lead.manage_reasons`. **بند تازه به منو افزوده نشد:** منو در ۱۲۸۰ پیکسل همین حالا بریده است (دور نوزدهم بند ۵). `chose_cash` در فهرست کنار گذاشتن نمی‌آید (API و trigger هم رد می‌کنند).
3. **مسدودی:** فرم «مسدود کردن شخص» (نوع و دلیل) و «رفع مسدودی شخص» (دلیل) در صفحه پرونده برای `lead.block_person`. انتخابگر نوع **بی پیش‌انتخاب** شروع می‌شود (برخلاف فرم بستن پرونده، دور نوزدهم بند ۵).
4. **ادغام دو شخص** (`lead.merge_persons`): ساخته نشد. به جست‌وجوی شخص نیاز دارد که پنل ندارد، و ادغام اثر گسترده دارد؛ فقط گزارش.
5. **عنوان دیدنی دو جدول سابقه:** تغییر نکرد؛ `DataTable` عنوان را عمداً فقط برای صفحه‌خوان می‌گذارد و تغییرش تأیید بصری مالک می‌خواهد.

## آزمون‌ها

- `apps/e2e/tests/leads.spec.ts`: دو آزمون تازه: «انتقال توسط مدیر استراتژی» (مشاور فرم را ندارد؛ پس از انتقال پرونده برای مشاور نیست) و «علت‌ها و مسدودی» (افزودن، ویرایش، کنار گذاشتن؛ `chose_cash` در فهرست کنار گذاشتن نیست؛ مسدود و رفع؛ مشاور پیوند و فرم را ندارد).
- `apps/api/test/credit/credit-visibility.int.test.ts`: آزمون تازه ش۵: پس از انتقال، وضعیت اعتباری با پرونده می‌رود (مشاور قبلی ۴۰۴، تازه ۲۰۰).
- جهش‌ها (همه قرمز): فرم انتقال فقط برای پرونده بسته؛ `chose_cash` در فهرست کنار گذاشتن؛ «رفع مسدودی» که مسدود می‌کند؛ `assigneeOf` با اولین مسئول سابقه به‌جای مسئول جاری.
