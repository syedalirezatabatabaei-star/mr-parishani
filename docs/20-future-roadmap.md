# ۲۰ — پس از نسخه اول: نقشه راه و قلاب‌های معماری

این موارد **در نسخه اول ساخته نمی‌شوند** (سند نقشه کل §۱۰). این سند فقط می‌گوید هر کدام به چه چیزی تکیه می‌کند تا در فازهای ۳ تا ۱۰ تصمیمی گرفته نشود که راهشان را ببندد. **هیچ تسکی از این سند بدون دستور صریح من اجرا نشود.**

| قابلیت | تکیه‌گاه موجود | قاعده‌ای که از الان رعایت شود |
|---|---|---|
| **اپ اندروید و iOS** (Expo) | API نسخه‌دار `/api/v1`، کلاینت تولیدشده از OpenAPI (۲-۱۱)، refresh چرخشی موبایل (۰-۴) | هیچ منطق کسب‌وکار فقط در وب نباشد؛ هر قابلیت بیمار از API در دسترس باشد |
| **درگاه پرداخت** (زرین‌پال و…) | رابط `PaymentProvider` (ADR-009، فاز ۶) | مسیر تخصیص پرداخت مستقل از کانال بماند؛ callback درگاه همان سرویس تأیید فیش را صدا بزند |
| **ربات پاسخگو** بیمار و پزشک | فرهنگ داده و نمای `analytics` (فاز ۷)، فیلتر سطح فیلد | ربات فقط از API با نشست همان کاربر بخواند، هرگز مستقیم از پایگاه داده؛ کاربر ثبت‌نام‌نکرده فقط سند راهنمای عمومی |
| **اتصال Issabel** و تحلیل مکالمات | جدول `collection_actions` آماده ستون تماس (فاز ۶) | شماره‌ها یکسان‌شده ذخیره شوند تا تطبیق تماس با `Person` ممکن باشد؛ فایل ضبط در فضای خصوصی |
| **تحلیل با هوش مصنوعی** برای مدیرعامل و کارشناسان | اسکیمای `analytics` بی‌نام‌شده روی replica (فاز ۷) | مدل داخلی یا خودمیزبان در اولویت (اینترنت ملی)؛ هیچ داده شخصی به سرویس بیرونی بدون تصمیم صریح |
| **جایگزینی کامل ویتایگر** | Person/Case، صف‌ها، اقدام‌ها، تیکت | داده ویتایگر با همان مسیر ورود گروهی و تشخیص تکراری سند ۰۵ وارد شود |
| **اتصال زنده Odoo 19** | خروجی فایل با شناسه خارجی یکتا (فاز ۵) | همان شناسه‌های خارجی در API استفاده شوند تا ارسال تکراری رخ ندهد |
| **امتیازدهی خودکار و استعلام برخط** | موتور امتیاز خالص و نسخه‌دار (فاز ۳) | تصمیم نهایی انسانی می‌ماند مگر تصمیم صریح؛ استعلام پشت رابط با adapter |
| **سایت عمومی جدید و انتقال سئو از وردپرس** | پروفایل‌های SSR، slug با ریدایرکت ۳۰۱ (۲-۸) | نقشه همه نشانی‌های فعلی وردپرس پیش از هر تغییر استخراج شود؛ هر نشانی قدیمی ریدایرکت ۳۰۱ بگیرد |
| **باشگاه مشتریان و چت بیمار با پزشک** | Person، رضایت پیامک | — |
| **شهرهای دیگر** | شهر در سلسله‌مراتب پیکربندی (ADR-010) | هیچ مقدار ثابت «اصفهان» در کد؛ همه از داده |
