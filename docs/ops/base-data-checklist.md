# چک‌لیست بارگذاری داده پایه واقعی (تسک ۱۰-۶)

ثبت ۱۴۰۵/۰۷/۲۳. **تصمیم ۱۰.۵:**
- داده در قالب ورود گروهی ۲-۹؛
- **اول روی staging، سپس با تأیید مالک روی production**؛
- یک نقطه تماس نام‌دار برای هر واحد.

**خود داده هنوز از کارفرما لازم است.** این فهرست ترتیب، ابزار و شرط هر مرحله است.

**قاعده‌های همه مراحل:**
- هر بارگذاری با کاربر نام‌دار و دلیل، و در `audit_events` ثبت می‌شود.
- هیچ بارگذاری مستقیم SQL روی جدول‌های برنامه (قاعده ۸)؛ فقط از پنل یا ورود گروهی.

- روی production، پیش از هر مرحله پشتیبان (R8).
