# واژه‌نامه

[بازگشت به فهرست](README.md)

همه مبلغ‌ها در سامانه **به ریال** نگه‌داری می‌شوند و فیلدهای ورود مبلغ هم ریالی‌اند. زیر هر فیلد مبلغ همان عدد به تومان دقیق نشان داده می‌شود (مثل «۲۴٬۶۹۱ تومان و ۴ ریال»).

> واژه‌نامه حقوقی (متن قرارداد و رضایت‌نامه‌ها) در انتظار مشاور حقوقی آرامش ثروت است. این واژه‌نامه فقط واژه‌های کاری سامانه است.

| واژه | معنی در سامانه |
|---|---|
| **آرامش ثروت** | شرکت وام‌دهنده. همه دریافت‌ها، کارمزدها و قراردادها به نام این شرکت است. |
| **سپهر سلامتی** | شرکت واسط که سامانه را اداره می‌کند. |
| **سرنخ** | کسی که برای درمان تماس گرفته یا فرم پر کرده و هنوز بیمار پرونده‌دار نیست. |
| **پرونده (سرنخ)** | مسیر یک شخص از تماس تا پایان درمان: مشاوره، نوبت، معاینه، پیش‌فاکتور. هر پرونده یک مسئول دارد. |
| **شخص** | یک انسان با کد ملی. می‌تواند چند موبایل داشته باشد. |
| **بیمار** | کسی که درمان می‌گیرد. |
| **وام‌گیرنده** | کسی که وام به نام اوست و اقساط را می‌پردازد. می‌تواند غیر از بیمار باشد (مثلاً پدر برای فرزند). |
| **ضامن** | کسی که پرداخت وام را تضمین می‌کند. هر پرونده حداکثر ۳ ضامن دارد؛ فقط دو ضامن اول برگه امتیاز می‌گیرند. |
| **نوبت** | زمان مراجعه نزد پزشک در یک محل کار. |
| **کد پذیرش** | کدی که بیمار هنگام ورود به مطب می‌گوید تا مرکز «پذیرش» را ثبت کند. |
| **معاینه** | پس از ثبت «معاینه شد» در نوبت، پزشک می‌تواند پیش‌فاکتور صادر کند. پیش از آن نه. |
| **پیش‌فاکتور** | فهرست خدمات و قیمت‌ها که پزشک پس از معاینه برای بیمار صادر می‌کند. پیش‌فرض ۳۰ روز معتبر است. هر اصلاح، نسخه تازه می‌سازد. |
| **تعرفه** | قیمت هر خدمت نزد یک پزشک در یک محل کار. ممکن است بازه باشد (از … تا …). |
| **خارج از تعرفه** | قیمت ردیف پیش‌فاکتور بیرون از تعرفه. دلیل می‌خواهد و کارشناس شبکه آن را بررسی می‌کند. |
| **دستمزد و مواد** | هر خدمت و هر ردیف پیش‌فاکتور «دستمزد» (کار پزشک) یا «مواد» است. در طرح فقط‌دستمزد، وام فقط به دستمزد تعلق می‌گیرد. |
| **طرح اعتباری (طرح وام)** | قواعد یک وام: تعداد اقساط، پیش‌پرداخت، کارمزد طرح، هزینه تشکیل پرونده و سقف. در پنل با تأیید دونفره تعریف می‌شود. |
| **پیش‌پرداخت** | بخشی از هزینه درمان که بیمار پیش از شارژ کیف، به حساب آرامش ثروت می‌ریزد. درصدش در طرح است. |
| **مبلغ وام** | سهم پیش‌فاکتور منهای پیش‌پرداخت (در طرح فقط‌دستمزد: دستمزد منهای پیش‌پرداخت). |
| **مبلغ مصوب** | مبلغی که تصمیم اعتباری تأیید کرده است. ممکن است کمتر از مبلغ وام درخواستی باشد. |
| **کسری** | فاصله مبلغ مصوب تا هزینه درمان. «کسری کم» (پیش‌فرض تا ۱۰٪ مبلغ مصوب) را بیمار نقد به پزشک می‌دهد؛ «کسری زیاد» درخواست جدا برای مابقی می‌خواهد. |
| **مابه‌التفاوت نقدی** | بخشی که بیمار هنگام درمان نقد به پزشک می‌دهد (کسری کم و هزینه مواد). از کیف اعتبار پرداخت نمی‌شود. |
| **هزینه تشکیل پرونده** | مبلغی که هنگام تکمیل پرونده با فیش پرداخت می‌شود. مبنا و درصدش در طرح است؛ در طرح‌های الحاقیه ۳٪ کل صورت‌حساب. |
| **بخشودگی (چک)** | اگر وام‌گیرنده دست‌کم تعداد معینی چک قسط بررسی‌شده بدهد، بخشی از هزینه تشکیل بخشیده می‌شود (طرح‌های الحاقیه: ۲٪ با ۵ چک). طرح‌های ۶ ماهه ندارند. |
| **تخفیف مسئول** | تخفیفی که مسئول تکمیل پرونده یا باشگاه با امضای خود روی هزینه تشکیل می‌دهد (طرح‌های الحاقیه: تا ۱٪). بی نفر دوم؛ در گزارش ماهانه. |
| **کارمزد طرح** | کارمزد وام. یا در اقساط پخش می‌شود («در اقساط»)، یا هنگام تکمیل یکجا با فیش پرداخت می‌شود («هنگام تکمیل»). |
| **بیعانه تشکیل** | مبلغی که پیش از تکمیل گرفته می‌شود (عدد پیشنهادی ۹۹۰٬۰۰۰ ریال). در پایلوت فقط مشخصاتش ثبت می‌شود و در دفتر کل ردیفی ندارد. پس از شارژ کیف برنمی‌گردد. |
| **باشگاه مشتریان** | عضویت ثبت‌شده با روز شروع و پایان. طرح باشگاه فقط به عضو عرضه می‌شود. عضویت هنگام ایجاد درخواست روی پرونده قفل می‌شود. |
| **پرونده اعتباری (درخواست اعتبار)** | درخواست وام روی یک پیش‌فاکتور تأییدشده. مبالغش با پیکربندی لحظه ثبت قفل می‌شود. |
| **رضایت اعتباری** | رضایت بیمار یا وام‌گیرنده به بررسی اطلاعات اعتباری، با کد پیامکی. |
| **امتیاز و رتبه** | خروجی موتور امتیاز از روی داده خام (شغل، سابقه، پوشش حقوق، تعهدات…). رتبه تعیین می‌کند چه کسی تصمیم می‌گیرد. |
| **مرجع تصمیم** | کسی که موتور برای تصمیم تعیین می‌کند: کارشناس و کنترل دوم، مدیر اعتبار، کمیته، یا «رد بی امکان تأیید». |
| **خارج از ماتریس** | تأییدی که موتور اجازه نمی‌دهد. فقط با مجوز ویژه، تأیید نفر دوم و کمیته. |
| **سقف مانده فعال وام‌گیرنده** | سقف جمع بدهی همه وام‌های باز یک نفر (عدد پیشنهادی ۱٬۵۰۰٬۰۰۰٬۰۰۰ ریال). هنگام تصمیم و هنگام شارژ سنجیده می‌شود. «۰» یعنی خاموش. |
| **قرارداد** | قرارداد وام به نام آرامش ثروت، با پذیرش الکترونیک (کد پیامکی) **و** امضای کاغذی. |
| **مدارک فیزیکی** | قرارداد امضاشده، چک‌ها و سفته‌ها و مدارک دیگر که باید به دفتر برسد. |
| **چک صیادی** | چکی که در سامانه صیاد بانک مرکزی ثبت شده است. کارشناس «تأیید ثبت در سامانه صیاد» را می‌زند. |
| **سفته** | **غیرفعال در پایلوت:** دریافت نمی‌شود (تصمیم کارفرما). |
| **تکمیل پرونده** | وقتی قرارداد پذیرفته، مدارک رسیده و بایگانی، فیش‌ها تأیید و شرط‌ها برقرار شد. |
| **کیف اعتبار** | حساب اعتبار درمان بیمار نزد پزشک معرفی‌شده. پول نقد نیست؛ فقط برای خدمت همان پزشک مصرف می‌شود. |
| **شارژ کیف** | آزاد شدن «مبلغ مصوب + پیش‌پرداخت» در کیف. دونفره: تکمیل پرونده درخواست می‌دهد، مالی تأیید می‌کند. اقساط از روز شارژ شروع می‌شوند. |
| **مجوز خدمت** | رزرو بخشی از کیف برای ردیف‌های یک جلسه درمان. پزشک صادر می‌کند؛ پیش‌فرض ۲۴ ساعت معتبر. |
| **کد خدمت** | کد پیامکی که بیمار پس از خدمت به پزشک می‌دهد تا خدمت ثبت شود. پیش‌فرض ۱۰ دقیقه معتبر، ۵ تلاش، ۳ ارسال. |
| **قطعی شدن خدمت** | پس از مهلت اعتراض (پیش‌فرض ۰ ساعت)، خدمت قطعی و بدهی به پزشک ثبت می‌شود. |
| **صورت‌وضعیت** | فهرست ماهانه خدمات و کارمزدهای هر پزشک و مبلغ قابل پرداخت. روز هدف پرداخت: ۱۰ هر ماه. |
| **کارمزد خدمت** | کارمزدی که از پزشک برای خدمت اعتباری یا نقدی کم می‌شود. نرخ از قرارداد پزشک یا مرکز؛ پیش‌فرض ۰. |
| **مدت قرارداد پزشک یا مرکز** | ۳، ۶ یا ۱۲ ماه. پس از پایان، خدمت تازه ثبت نمی‌شود. هشدار ۳۰ روز پیش از پایان. |
| **اعتراض (شکایت مالی)** | اعتراض پزشک یا مرکز به یک قلم تسویه. قلم تا تصمیم حسابداری در صورت‌وضعیت نمی‌آید. |
| **قسط** | مبلغ ماهانه بازپرداخت. سررسیدها از روز شارژ حساب می‌شوند. |
| **فیش** | رسید واریز بانکی که بیمار یا کارکنان بارگذاری می‌کنند. مالی تأیید یا رد می‌کند. |
| **تخصیص** | نشستن پرداخت تأییدشده روی قدیمی‌ترین قسط باز؛ خودکار. |
| **حساب معلق** | پولی که رسیده ولی به قسطی ننشسته (مثلاً اضافه‌پرداخت). تعیین تکلیف دستی با حسابداری. |
| **معوق** | قسطی که از سررسیدش گذشته و کامل پرداخت نشده. |
| **وعده پرداخت** | قول وام‌گیرنده به پرداخت در روز معین، که واحد معوقات ثبت می‌کند. |
| **تشدید** | رفتن پرونده معوق به مرحله بعد وصول (اطلاع به ضامن، اجرای چک، ارجاع حقوقی). |
| **اجرای چک** | ارائه چک به بانک برای وصول. سه نفر متفاوت: پیشنهاد، تأیید مدیر وصول، تأیید مالی. |
| **استرداد ابزار** | پس دادن چک‌ها پس از تسویه کامل وام. |
| **ابطال مانده** | باطل کردن بخشی یا همه مانده مصرف‌نشده کیف. از آخرین اقساط دست‌نخورده کم می‌شود. دونفره. |
| **انصراف پیش از شارژ** | لغو پرونده پیش از شارژ کیف. همه فیش‌های تأییدشده **بدون خسارت** مسترد می‌شوند. دونفره. |
| **انصراف پس از شارژ** | بستن کیف پس از شارژ: مانده مصرف‌نشده باطل، کارمزد اقساط سررسیدنشده بخشوده، بخش کسب‌نشده کارمزد نقدی برگشت، و خسارت انصراف یکجا با سررسید جدا. |
| **خسارت انصراف** | پیش‌فرض ۱۸٪ مبلغ مصوب وام (نه کارمزد و نه پیش‌پرداخت)، با سررسید ۳۰ روز. نرخ هر پرونده ۰ تا ۱۸٪، دونفره، فقط پیش از ساخت قرارداد. |
| **تغییر پزشک** | بردن کیف به پزشک دیگری از همان رشته و شهر. دونفره. |
| **انتقال اعتبار** | **غیرفعال در پایلوت:** دادن بخشی از کیف به گیرنده مجاز. پرچمش خاموش است. |
| **تیکت** | پرسش، درخواست یا شکایت، با مهلت پاسخ و ارجاع بین واحدها. |
| **کمپین (ارسال گروهی)** | پیامک به گروهی از گیرندگان با فیلتر نام‌دار. سازنده تأیید نمی‌کند؛ بالای آستانه (۲۰۰ گیرنده) فقط مدیر استراتژی. |
| **تعطیلات دسته‌ای** | ثبت چند روز تعطیل در یک درخواست، با تأیید نفر دوم. روزهای قمری فقط پس از اعلام رسمی. |
| **پیکربندی نسخه‌دار** | هر عدد کسب‌وکار (نرخ، سقف، مهلت) در پایگاه داده است، نه کد. هر تغییر نسخه تازه، دونفره، و فقط روی رکوردهای بعدی اثر دارد. |
| **دفتر کل** | ثبت‌های مالی سامانه. فقط افزودنی است: هیچ ثبتی ویرایش یا حذف نمی‌شود؛ اصلاح فقط با سند معکوس. |
| **launch-check** | بررسی خودکار پیش از راه‌اندازی (`pnpm ops:launch-check`). هر FAIL مانع راه‌اندازی است. |
