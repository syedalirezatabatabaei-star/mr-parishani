# جریان کامل یک پرونده: از ثبت تا تسویه

[بازگشت به فهرست](README.md) · [واژه‌نامه](glossary.md)

این صفحه نشان می‌دهد هر نقش کجای زنجیره کار می‌کند. جزئیات هر گام در راهنمای همان نقش است.
مثال با اعداد ساختگی: بیمار «سارا نمونه» برای درمان دندان، پیش‌فاکتور ۱۲۰٬۰۰۰٬۰۰۰ ریال.

## نمای کلی

```
سرنخ ← مشاوره ← نوبت ← معاینه ← پیش‌فاکتور ← تأیید بیمار و انتخاب طرح
  ← درخواست اعتبار (رضایت، مدارک، ضامن) ← امتیاز ← تصمیم (دونفره یا کمیته)
  ← تکمیل پرونده (قرارداد، مدارک فیزیکی، چک، فیش‌ها) ← شارژ کیف (دونفره)
  ← مجوز خدمت و کد بیمار ← قطعی شدن خدمت ← صورت‌وضعیت و پرداخت به پزشک (دونفره)
  ← اقساط و فیش ← (در صورت تأخیر) معوقات و وصول ← تسویه وام و استرداد چک
```

## نمونه عددی (ساختگی)

طرح نمونه: ۱۲ قسط، پیش‌پرداخت ۲۰٪، کارمزد طرح ۱۰٪ در اقساط، هزینه تشکیل ۳٪ کل صورت‌حساب. **این اعداد فقط نمونه‌اند؛ اعداد واقعی هر طرح در پنل تعریف می‌شوند.**

| قلم | محاسبه | مبلغ (ریال) |
|---|---|---|
| پیش‌فاکتور | — | ۱۲۰٬۰۰۰٬۰۰۰ |
| پیش‌پرداخت | ۲۰٪ × ۱۲۰٬۰۰۰٬۰۰۰ | ۲۴٬۰۰۰٬۰۰۰ |
| مبلغ وام | ۱۲۰٬۰۰۰٬۰۰۰ − ۲۴٬۰۰۰٬۰۰۰ | ۹۶٬۰۰۰٬۰۰۰ |
| کارمزد طرح (در اقساط) | ۱۰٪ × ۹۶٬۰۰۰٬۰۰۰ | ۹٬۶۰۰٬۰۰۰ |
| جمع اقساط | ۹۶٬۰۰۰٬۰۰۰ + ۹٬۶۰۰٬۰۰۰ | ۱۰۵٬۶۰۰٬۰۰۰ |
| هزینه تشکیل پرونده | ۳٪ × ۱۲۰٬۰۰۰٬۰۰۰ | ۳٬۶۰۰٬۰۰۰ |
| با ۵ چک قسط بررسی‌شده (بخشودگی ۲٪) | ۱٪ × ۱۲۰٬۰۰۰٬۰۰۰ | ۱٬۲۰۰٬۰۰۰ |
| با ۵ چک و تخفیف مسئول ۱٪ | ۰٪ | ۰ |
| شارژ کیف | وام + پیش‌پرداخت | ۱۲۰٬۰۰۰٬۰۰۰ |

- مبالغ درصدی طرح‌های تازه رو به پایین تا مضرب ۱۰ ریال گرد می‌شوند. وام گرد نمی‌شود.
- واحد گرد کردن مبلغ قسط از پیکربندی قفل‌شده پرونده است (پیش‌فرض ۱۰٬۰۰۰ ریال).
- پزشک از کیف کل ۱۲۰٬۰۰۰٬۰۰۰ را برای خدمت می‌گیرد، منهای کارمزد خدمت در صورت‌وضعیت.

### همان نمونه با طرح فقط‌دستمزد (ADR-050)

پیش‌فاکتور ۱۰۰٬۰۰۰٬۰۰۰: دستمزد ۸۰٬۰۰۰٬۰۰۰ و مواد ۲۰٬۰۰۰٬۰۰۰. پیش‌پرداخت ۱۸٪ از **کل**:

| قلم | مبلغ (ریال) |
|---|---|
| پیش‌پرداخت (۱۸٪ × ۱۰۰٬۰۰۰٬۰۰۰) | ۱۸٬۰۰۰٬۰۰۰ |
| مبلغ وام (۸۰٬۰۰۰٬۰۰۰ − ۱۸٬۰۰۰٬۰۰۰) | ۶۲٬۰۰۰٬۰۰۰ |
| هزینه مواد، نقد به پزشک، بیرون از کیف | ۲۰٬۰۰۰٬۰۰۰ |
| شارژ کیف (وام + پیش‌پرداخت) | ۸۰٬۰۰۰٬۰۰۰ |

اگر پیش‌پرداخت به دستمزد برسد یا از آن بیشتر شود، این طرح برای آن پیش‌فاکتور عرضه نمی‌شود و بیمار پیام خنثی می‌بیند: «این طرح برای این پیش‌فاکتور قابل ارائه نیست؛ با کارشناس تماس بگیرید.»
