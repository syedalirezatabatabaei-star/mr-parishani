# دستورالعمل‌های عملیاتی (تسک ۱۰-۹)

ثبت ۱۴۰۵/۰۷/۲۳. هر دستورالعمل برای نوبت‌کار عملیات است و با محیط واقعی (۱۰-۱) نهایی می‌شود. نام میزبان‌ها و شماره‌ها پس از ۱۰-۱ جای `<...>` را می‌گیرند.

| دستورالعمل | کی |
|---|---|
| [incident.md](incident.md) | هر خرابی یا هشدار بحرانی؛ نقطه شروع |
| [backup-restore.md](backup-restore.md) | از دست رفتن پایگاه یا داده، یا تمرین بازیابی |
| [ledger-mismatch.md](ledger-mismatch.md) | هشدار تطبیق دفتر کل، تسویه یا پیش‌پرداخت |
| [kavenegar-outage.md](kavenegar-outage.md) | پیامک نمی‌رود |
| [national-internet.md](national-internet.md) | قطع اینترنت بین‌الملل |
| [key-rotation.md](key-rotation.md) | چرخش کلید رمزگذاری، یا گمان افشای راز |
| [staff-offboarding.md](staff-offboarding.md) | رفتن کارمند |
| [release.md](release.md) | انتشار نسخه تازه |

**قاعده‌های مشترک همه دستورالعمل‌ها:**

1. **هیچ `UPDATE` یا `DELETE` دستی روی ثبت مالی** (قاعده ۳). اصلاح فقط با سند معکوس از مسیر برنامه.
2. **هیچ داده شخصی** در پیام، تیکت، لاگ یا گروه گفت‌وگو (قاعده ۳۰): فقط شناسه.
3. **پیش از هر کار نوشتنی روی پایگاه:** پشتیبان (`pg_dump -Fc \| age`، R8).
4. **هر اقدام با زمان (UTC و تهران)** در گزارش حادثه ثبت می‌شود.
