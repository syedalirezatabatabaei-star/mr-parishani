2. **کد مالی:** تأیید بازبین انسانی ثبت شده (۱۰-۰).
3. **`CHANGELOG.md` و برچسب نسخه** (رویه انتشار مخزن).
4. **مهاجرت‌ها:**
   - همه expand/contract و با نسخه قبل سازگار؛
